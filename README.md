# Impossible Flappy Bird

A small Flappy Bird-style game I made with Python and Pygame.

Everything is drawn in the game itself, so there are no image or sprite files needed. The bird, pipes, clouds, ground, and text are all made with Pygame.

## What it has

- Pixel-style bird with animated wings
- Pipes with random gaps
- Score counter
- Countdown before the game starts
- Moving clouds
- Simple ground
- Game over screen
- Press Space to restart
- Jump sound
- Countdown sounds
- Pipe sound
- Game over sound
- Sound on/off button
- No external images or game assets

## Controls

- **Space** — Jump
- **Space after losing** — Restart
- **M** — Turn sound on/off
- **Esc** — Quit

## Requirements

- Python 3.8+
- Pygame

Install Pygame:

```bash
pip install pygame
```
